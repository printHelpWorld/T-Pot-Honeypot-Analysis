# T-Pot-Honeypot-Analysis

Last week, I deployed a T-Pot honeypot on a cloud VPS and let it sit for just 4 hours. When I checked the logs, I found over 5,000 brute-force attempts. After sifting through the noise, I found something much more interesting: a highly structured botnet operating with a strict division of labor. This led me to write a full Threat Intelligence report breaking down the TTPs, analyzing the payloads, and mapping the botnet economy.
